# Privacy Policy

**Last Updated: May 9, 2026**

## Introduction

"Aliyun Account Manager" is a Chrome browser extension designed to help users manage and switch between multiple Aliyun accounts. We take your privacy seriously, and this Privacy Policy explains how we collect, use, and protect your information.

## Information Collection

### Information We Collect

This extension only stores the following information locally:

1. **Aliyun Account Cookies**: Used to maintain your login status and enable account switching
2. **Account Display Names**: Custom aliases you set for your accounts
3. **Account Creation Time**: Used to display the login time of accounts

### How We Collect Information

- We read login-related cookies from the `aliyun.com` domain via Chrome Cookies API
- We store account information locally via Chrome Storage API

### Information We Do NOT Collect

- We **do not** collect your personal identification information
- We **do not** collect your passwords
- We **do not** collect your browsing history
- We **do not** send any data to external servers

## Information Usage

The collected information is only used for the following purposes:

1. **Account Management**: Save and restore your Aliyun login status
2. **Account Switching**: Quickly switch between different Aliyun accounts
3. **Status Display**: Show the current account's login status on the extension icon

## Information Storage

- All data is stored locally in your browser (Chrome Storage Local)
- Data is not uploaded to any cloud servers
- Data is not shared with any third parties

## Information Security

- This extension only requests minimal necessary permissions
- Data is stored only in your local browser environment
- You can clear all stored data at any time by removing the extension

## Third-Party Services

This extension does not integrate any third-party analytics tools, advertising services, or external APIs.

## Your Rights

You have full control over your data:

1. **View Data**: View saved accounts through the extension popup
2. **Delete Data**: Delete individual accounts or all account data
3. **Export Data**: Data is stored in Chrome local storage and can be exported via browser tools
4. **Clear Data**: Uninstalling the extension will automatically clear all related data

## Children's Privacy

This extension is not intended for children under 13. We do not knowingly collect personal information from children.

## Policy Changes

We may update this Privacy Policy from time to time. Updated policies will be posted on this page, and we recommend checking periodically.

## Contact Us

If you have any questions or suggestions about this Privacy Policy, please contact us through GitHub Issues.

## Permissions Explanation

This extension requests the following permissions and their purposes:

| Permission | Purpose |
|------------|---------|
| `cookies` | Read and restore Aliyun login cookies |
| `storage` | Store account information locally |
| `tabs` | Refresh pages to apply new account status |
